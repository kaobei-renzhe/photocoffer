改动要点

黑底口径：文字 / 勾边 / 强调色全部复用深色主题既有的 --lb-* 变量，不新增色值
  • ① 触发规则改写：删掉「任意 pointermove 即淡入」。主入口＝进入上下 68px 边缘带立即 150ms 淡入；辅助＝图片点击，或累计位移 ≥32px 且驻留 ≥150ms，设 <8px 抖动死区。淡出 3s / 200ms。
  • ② 控件分级：常显五个 缩放− / 缩放+ / 适应 / ⋯ / ×；141% 与 0° 删常显，数值变化改 1s toast；翻页改左右大热区 + 唤出态箭头，不占工具条名额。
  • ③ 让路：框选拖拽中、档案面板打开、幻灯片播放、二级展开、指针按下 → 冻结隐藏计时，操作结束才重启；播放态锁定常显「停止」出口。
  • ④ 无障碍：控件常驻 DOM 与 a11y 树，静止仅降 opacity + pointer-events:none；禁用 inert / aria-hidden / display:none；:focus-within 让 Tab 一聚焦即整条淡入并冻结计时。
  • ⑤ 误伤排除：框选草稿压在照片上，近白虚线 #F2F5F8 + 黑外描边 是刻意双描边，原样保留，不换成 --lb-* 变量。
