# 名称可用性验证报告

> 日期：2026-11-14
> 范围：App Store / 微软商店 / 公开网页 / 域名 RDAP / GitHub 仓库搜索
> 目的：为「片匣」验证英文名候选，并复核中文名占用情况

---

## ⚠️ 一、最重要的发现：中文名「片匣」已被占用

之前判断「中文侧没有同名 App」是**错的**（当时的检索词偏向摄影类，把下面的结果过滤掉了）。实际情况：

| 占用方 | 类型 | 说明 |
|---|---|---|
| **GitHub `dengji85/avm`** — 「**片匣 · AVM (Adult Video Manager)**」 | 开源桌面软件 | 成人视频管理器。**本地优先、零账号、去重归并、语义搜索、卡片墙、分面筛选** —— 产品定位与本项目高度重合，且名字就叫「片匣」。公开搜索「片匣」时这是首条结果 |
| App Store《私人知识库》(`id6787904180`) | iOS/iPadOS App | 应用名为「私人知识库」，但正文反复以「**片匣**」称呼产品（「片匣帮你把这些碎片整理成一张张知识卡片」） |
| 《梦幻影韵播放器》 | 移动 App | 内含功能模块「**片匣**（本地片库）」 |

**风险等级：高。** 尤其是第一个：同名 + 同为本地媒体库 + 同为「片」的语义，而且内容品类敏感。用户搜索产品名时会直接被带到那个项目，不利于任何分发或口碑传播。

**结论：真正干净的名字只有一个 `Pianxia`（拼音）。** 但它与中文名绑定——如果中文名要换，这个也就失效了。

## 四、规律

本轮一共验证 8 个英文候选 + 1 个中文名，**没有一个现成的好词是空的**：

- 短、好念、有含义的英文词，基本都被软件产品占过
- 中文里「片 / 匣 / 挑 / 择 / 留」这几个字的组合，也基本被照片类或媒体库类产品用尽
- 连「片匣」这种看起来冷门的组合，都被一个成人视频管理器占了

这和前面几轮撞到「光谱挑片」「择片」「Stow」「留白相册」的结论一致：**这个品类的描述性词库已经枯竭**，继续在词库里找，成本会越来越高。

---

## 五、可选路径

| 路径 | 做法 | 代价 |
|---|---|---|
| **A. 换中文名 + 造英文名** | 中文重新找（避开已占组合），英文用自造词（`Pianxia` 这类无含义代号） | 需要再走一轮命名；但能彻底避开撞车 |
| **B. 换中文名 + 不要英文名** | 只用中文名，产品内和商店都只写中文 | 出海/国际化受限，但中文用户无认知成本 |
| **C. 保留「片匣」** | 接受搜索结果被 AVM 占据 | 分发风险高，且同名项目内容品类敏感，**不推荐** |
| **D. 保留但加限定** | 如「片匣 · 摄影图库」 | 名字变长，且仍会与 AVM 混淆 |

---

## 六、验证方法的局限

- **商标未做正式检索**：RDAP / GitHub / 网页搜索只能查「有没有人在用」，不能判断「有没有注册商标」。正式定名前需查中国商标网与 USPTO
- **RDAP 判读**：`.com` 返回 200 且有 `ldhName` 判定为已注册；`.io` 普遍返回 404（rdap.org 对部分后缀支持不全），不能据此断定可注册
- **App Store / 微软商店**：通过公开网页检索，未逐一下载核对包名

## 七、决策过程与最终定名（同日收尾）

用户先选了「换中文名 + 代号式路线」，据此定过 **砚白**（GitHub 0、无同名 App）。
但用户随后反馈「**砚白感觉不知道是什么类型的 app**」—— 这是代号式的固有代价，而且对这个产品不成立。

**关键反思**：前面把撞车标准定得太严，把「不同品类、不同平台的小 App」也算撞车，
于是把好懂的描述性词全部否光。真正要避的只有 **同品类 + 同平台 + 同名**。
按这个标准重筛半描述性词，得到四个干净候选：存照 / 图匣 / 拣片 / 影格（影匣被抖音下载器占用，否决）。

用户最终选定：

> **存照**（cún zhào）

| 检查 | 结果 |
|---|---|
| GitHub 同名仓库 | **0** |
| 同名 App / 软件 | **无**（同品类无占用） |
| 域名 | `cunzhao.app` / `.dev` / `.net` 未查到注册记录；`.com` 已注册 |
| 类型感 | 「照」= 照片，「存」= 本地归档，一眼知道是照片工具 |
| 语义纵深 | 成语「立此存照」；读音 2–4 声，先扬后落 |

已通过 `scripts/rename-product.py 砚白 存照` 一键落地：41 处文案、`productName`、
`shortcutName`、`appId`（→ `com.silvermoon.cunzhao`）、迁移链加入「砚白」为旧名。
`npm run typecheck` 通过，`npm test` 26 文件 / 155 测试全通过。

**以 `design/final-spec.md` 为最终交付。** 本文件保留为验证过程记录。
