## 目录

| 目录 | 放什么 |
| --- | --- |
| `architecture/` | 架构、数据安全、平台适配、外部格式与性能实测 |
| `product/` | 界面、交互、AI 能力相关的产品方案 |
| `release/` | 版本发布说明 |
| `assets/` | 文档配图与对照页 |
