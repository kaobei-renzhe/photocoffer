# 模型能力边界与可替换关系

> 状态：与当前实现对齐（2026-11-22）
> 目的：说清「哪些 AI 能力只能用内嵌模型、哪些只能用自定义模型、哪些可以互换」，以及照片会去哪里、怎么计量。

---

## 一、三类模型，三种输出

| 类别 | 代表 | 输出 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- | --- |
| 内嵌 · 图文对齐（embedding） | Chinese-CLIP / SigLIP 2 | 一个向量 | 语义检索、找相似、零样本分类 | 生成文字、做审美判断 |
| 内嵌 · 物体检测 | DETR-ResNet-50 | 检测框 + 类别 | 判断画面里有没有人、在哪 | 理解语义、判断好坏 |
| 自定义 · 视觉语言模型（VLM） | Ollama / 本机 OpenAI 兼容端点 / 外部 API | 自然语言 | 评分、建议、筛选、研读、自动分类 | 给出向量、给出检测框 |

一句话：**内嵌模型输出「数」，VLM 输出「话」。这是类型差异，不是效果差异。**

## 二、能力矩阵

| 任务 | 内嵌模型 | VLM（本机或外部） | 可替换性 | 计量 |
| --- | --- | --- | --- | --- |
| 语义检索 / 找相似 | ✅ Chinese-CLIP / SigLIP 2 | ❌ 当前不支持 | 只能同类换 embedding，且必须重建索引 | 不计 |
| 自动分类 | ✅ 零样本，默认全库 | ✅ 自定义模型，最多 12 张 | 唯一真正可互换 | 本机不计；外部计入 |
| 人像检测 | ✅ DETR，给检测框 | ❌ 给不出框 | 不可替换 | 不计 |
| 照片质量评分 | ❌ | ✅ | 只能 VLM | 本机不计；外部计入 |
| 后期建议 | ❌ | ✅ | 只能 VLM | 本机不计；外部计入 |
| 智能筛选 | ❌ | ✅ | 只能 VLM | 本机不计；外部计入 |
| 研读反问 | ❌ | ✅ | 只能 VLM | 本机不计；外部计入 |

## 三、可替换关系

### 1. 同类互换（安全）

| 替换 | 影响 | 代价 |
| --- | --- | --- |
| Chinese-CLIP ↔ SigLIP 2 | 维度 512 ↔ 768，向量空间不同 | 必须重建索引；`embeddings` 表的 `(item_id, model)` 双主键会隔离新旧向量 |
| OpenAI 兼容 ↔ Anthropic ↔ 任意服务商 | 只换调用端 | 换地址、模型名和 Key，数据不动 |

### 2. 跨类互换（只有一处）

**自动分类：本地零样本 ↔ 自定义 VLM**

| | 本地零样本 | 自定义 VLM |
| --- | --- | --- |
| 成本 | 免费 | 本机免费；外部按张计费 |
| 速度 | 全库秒级到分钟级 | 每张一次请求，最多 12 张 |
| 类目 | 固定 14 类（`AUTO_TAG_CATEGORIES`） | 同一套白名单，判断更准 |
| 隐私 | 照片不出本机 | 本机端点不出机；外部 API 会上传 |
| 定位 | 全库粗分 | 少量精选照片的精确标注 |

### 3. 不可互换

| 组合 | 为什么不行 |
| --- | --- |
| 用 VLM 做语义检索 | VLM 输出文字，产不出可比较的向量；逐张问成本不可接受 |
| 用 CLIP 做审美评分 | 相似度无法表达「构图三分、曝光略欠」这类判断 |
| 用 VLM 做人像检测 | 能回答「有没有人」，但给不出检测框，也不适合批量 |

## 四、照片去向与计量

### 本机端点

只认回环地址：

- `http://localhost:...`
- `http://127.0.0.1:...`
- `http://[::1]:...`

本机端点：

- 不需要 API Key；
- 不计量、不弹额度提醒、不触发熔断；
- 照片不会离开本机。

局域网 IP、内网域名、Docker 网桥都按外部处理。存照只能按地址判断，无法审计用户自建的反向代理。

### 外部端点

- 必须使用 https；
- 图片会发送到用户配置的服务商；
- 按「照片张数」计量，不按 token；
- 默认阈值：单次超过 10 张软提醒、今日超过 50 张再次提醒、今日超过 100 张硬暂停；
- 硬暂停后只能等到次日 0 点或到「设置 → 大模型 → 用量与限额」手动重置；
- 连续 3 次外部调用失败会熔断 5 分钟；本机调用不受影响。

## 五、当前不做的替换

| 不做 | 原因 |
| --- | --- |
| 外部 embedding API 替换 CLIP | 会把缩略图传给第三方，与「照片不上传」的核心承诺冲突 |
| 本机自定义 ONNX embedding 导入 | 需要模型描述符、导入校验、重建索引，是独立工程 |
| 用 VLM 替换人像检测 | 给不出检测框 |
| 自动在本机失败时切到外部 | 用户不知道照片何时外发，违背边界透明原则 |
