# 界面改进方案（B · 重组）

> 目标：解决「复杂」和「不美观」两个问题。
> 原则：**不砍功能，只做收纳**——高频露出，低频收进抽屉，但随时找得到。
> 效果稿：`design/ui-refresh.html`（真实照片、可缩放对比）

---

## 0. 诊断：复杂感从哪来

不是"元素太多"，是**没有层级**。每个控件看起来一样重要，眼睛找不到落点。

| 问题 | 具体表现 |
| --- | --- |
| 顶部 13 个控件平铺 | 第一层 7 个 + 第二层 6 个，找东西要扫全屏 |
| 侧栏四种东西竖着叠 | 导航 / 目录树 / 标签 / 5 个管理按钮，中间没分隔 |
| 8 个彩色圆点 | 全屏饱和度最高的元素，在跟照片抢注意力 |
| 间距全是 4–8px | 没有疏密节奏，整片糊在一起 |
| accent 用得太散 | 选中态、按钮、标签点、图标全是蓝紫 |
| 圆角三种混用 | 6 / 8 / 12px 混着来 |

---

## 1. 设计规格（照这个改）

### 间距：只用四档

```
4px   图标与文字之间
8px   控件内部 padding
12px  元素之间
18px  区块之间
```

现在全是 4/6/8，没有任何一档是"区块级"，所以看起来永远挤。

### 字号：五档

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 分组标题（源目录 / 标签） | 11px | 500，字距 +0.08em |
| 次要信息（数字、提示） | 11.5px | 400 |
| 正文（列表项、标签） | 12.5px | 400 |
| 导航项 | 13px | 400（选中 500） |
| 面板标题 | 13.5px | 500 |

### 灰度：三层就够，别新增变量

项目里现有的就是三层，**不要新建 `--ink`、`--ink2` 这套新名字**——254 处引用全都要跟着改，收益却为零。

```css
/* 现有三层，括号里是对 --panel(#101319) 的实测对比度 */
--text:  #e7ebf2   /* 主文字  15.4  ✓ */
--muted: #8b94a7   /* 次要     6.1  ✓ */
--faint: #5b6474   /* 弱       3.1  ✗ 不达标 */
```

**问题不在层数，只在第三层太淡。** 前两层差距已经很大（15.4 vs 6.1），视觉上完全分得开；`--faint` 只有 3.1，低于 4.5 的可读下限——这才是"小字看不清"的原因。

所以这一步**不需要新设计，直接套用 `主题色与对比度优化方案.md` 的 `--faint` 替换值**（dark → `#737e91`，其余 6 套同理）。改完三层自然就清晰了。

> 原来我写的"补成四层"是错的判断：我误以为 `--muted` 和 `--faint` 分不开，实测差了近一倍。

### 颜色：一个强调色

项目现在是 `--accent: #7aa2f7`（浅蓝紫），**色值本身不用改**——问题不在颜色选得不好，在它出现的次数太多。

**只出现在三个地方**：选中态的底色、选中的图标、主操作按钮。

其余地方全部去掉——特别是标签的彩色圆点。

> 我先前在稿子里写过 `#5b6bd6`，那只是设计稿的配色，别照着改。**换成它没有任何收益，还会让所有 accent 出现的地方一起变色。**

### 圆角：两档

```
8px   所有控件（按钮、输入框、列表项）
10px  卡片（照片、面板）
```

## 2. 逐区域改法

### 2.1 顶部工具条：13 → 4 个

**现在**：搜索 / 语义 / 筛选 / 最新导入 / 导入选片 / 张数 / 缩略图滑块 + 星级 / AI 评分 / 构图 / 旗标 / AI 筛选 / 展开连拍 / 主色 / 保存筛选

**改成**：搜索 + 筛选（带角标）+ 排序 + 视图 + 张数，**一行**

收进「筛选」抽屉的：星级、AI 评分、构图、旗标、主色、AI 筛选、保存筛选。

> **角标是关键**：`筛选 ③` 那个数字告诉你当前有几个条件生效。现在条件散在两层里，经常"怎么只剩 3 张了"然后找半天。

「导入选片结果」是低频操作，移到侧栏 `⋯` 菜单或工具栏溢出菜单。

### 2.2 侧栏：四段竖叠 → 三段有间隔

```
[品牌 + 切换图库]
─────────────────
全部图片      30,409      ← 导航段
人像工作台
选片记录
─────────────────（分隔线）
源目录            1       ← 库内容段
  照片        31,864
                  ← 18px 空隙
文件夹            0
  还没有文件夹
                  ← 18px 空隙
标签             23
  交通工具        806
  …（只显示前 10 个）
  全部 23 个标签 →
─────────────────
[导入图片]  [⋯]           ← 操作段
```

**三个改动：**

1. **标签去掉彩色圆点**。那 8 个点是全屏最跳的东西。想保留颜色识别的话，hover 时再出现。
2. **分组标题加字距和字重**（11px / 500 / +0.08em），现在和列表项一样大，看不出是标题。
3. **底部 5 个按钮 → 主按钮 + ⋯**。刷新 / 文件夹 / 扫描 / 查重都是低频操作，不该占最显眼的位置。

### 2.3 照片网格：加呼吸感

| 项 | 现在 | 改成 |
| --- | --- | --- |
| 列间距 | 8px | **14px** |
| 卡片圆角 | 无 / 4px | **10px** |
| 卡片阴影 | 无（纯边框） | `0 1px 2px rgba(25,28,34,.05)` |
| 悬停 | 无变化 | 上移 2px + 阴影加深 |
| 选中态 | 边框 | **右上角圆点徽章** |

现在纯边框 + 8px 间距，十几张照片糊成一片，看不出单张。

### 2.4 详情面板（如果一起改）

- 分区间距 18px（现在是 12px）
- 分区标题用 11px / 500 / 字距
- 表单控件的 label 和 value 拉开层级

## 3. 施工顺序

| # | 改哪里 | 做什么 | 验证 |
| --- | --- | --- | --- |
| 0 | `styles.css` | **先做配色那批**（`--faint` 提亮、`--panel` 拉开），见 `主题色与对比度优化方案.md` | 小字看得清了 |
| 1 | `styles.css` | 间距 / 圆角 token（**颜色此时不要动，第 0 步已经改完**） | 全局节奏感出来，其他不变 |
| 2 | `Sidebar.tsx` | 标签去彩点、分组标题加字距、底部按钮收进 ⋯ | 侧栏看起来"轻"了 |
| 3 | `Toolbar.tsx` | 13 个控件压成一行 + 筛选抽屉 | 顶部只剩一行，筛选能用 |
| 4 | `Gallery.tsx` | 间距 14 / 圆角 10 / 阴影 / 悬停 | 照片之间能分开 |
| 5 | 全局 | 圆角统一 8 / 10 两档 | 不再有三种圆角混用 |
| 6 | 详情面板 | 分区间距与标题层级 | 信息不再糊成一块 |

**第 1 步单独做、单独验**：只改间距和圆角，不动布局结构。如果这几步做完发现"其实没那么难看"，后面几步的收益判断会更准。

> ⚠️ **颜色只在一处改**：全部集中在配色那批（第 0 步）。不要把 `--faint` 的提亮又写进界面重组里，否则两边各改一次，第二次会覆盖第一次的效果判断。

## 4. 明确不做的

| 想法 | 为什么不做 |
| --- | --- |
| 删掉低频功能 | 每样都是真功能，删了主人两周后自己会想不起来，方向是**收纳**不是砍 |
| 换深色主题 | 深色不解决"复杂"，只是换个壳。先把层级理顺 |
| 重画所有图标 | lucide 线性图标本身没问题，问题在大小和颜色 |
| 上动画/过渡效果 | 会显得"高级"三分钟，然后开始觉得慢 |

---

## 5. 验收

- [ ] 顶部只剩一行，数得清控件（≤5 个）
- [ ] 筛选角标能正确显示生效条件数
- [ ] 侧栏三个分区一眼能分开，不需要细看分隔线
- [ ] 标签列表里没有任何彩色圆点（或只在 hover 时出现）
- [ ] 照片之间有明显间隔，单张能"跳出来"
- [ ] 全屏只有一种强调色
- [ ] 圆角只有两种

最后一条自检方法：**眯起眼睛看截图，如果只能看到照片和几个清晰的区块，就成了**；如果还看到一堆同等的方块在抢注意力，就是没改到位。

---

## 6. 附：三个力度对比

| 力度 | 内容 | 工时 | 效果 |
| --- | --- | --- | --- |
| A 微调 | 只改颜色间距圆角，不动结构 | 1 天 | 看着舒服，但复杂感还在 |
| **B 重组（本方案）** | 顶部收抽屉 + 侧栏分段 + 网格留白 | 3–5 天 | 层级清晰，一眼能扫 |
| C 场景化 | 按任务切换工作区（浏览/分类/选片/维护） | 1–2 周 | 上限最高，但要先把 B 做完 |
