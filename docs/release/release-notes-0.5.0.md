## 存照 v0.5.0

给摄影师的本地图片库。照片留在你的硬盘上，找图、挑片、交付都在一个窗口里完成。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10 / 11 | `photocoffer-0.5.0-win-x64-setup.exe` | 未签名，首次运行点「更多信息 → 仍要运行」 |
| macOS | 暂未提供预编译包 | 原生模块必须在 macOS 上安装，需从源码构建：`npm ci && npm run dist:mac` |

装完打开一次即可，不需要联网。

### 这次改了什么

**灯箱更沉浸**

看片时界面不再抢注意力：去掉常驻的三条白色胶囊，鼠标移到窗口上下边缘才唤出工具，移开三秒自动退回去。

- 舞台固定纯黑，换个皮肤灯箱也还是黑的——界面色不再干扰对照片的判断
- 静止态只留 5 个极淡控件：缩放 −/+、适应、更多、关闭
- 旋转和档案提到工具条，不用再翻二级菜单
- 手抖不会误触发（<8px 死区），键盘按 Tab 一聚焦整条浮入并停住

**顶部菜单精简**

从 6 项（文件 / 编辑 / 照片 / 视图 / 帮助）收敛为 **文件 + 设置** 两项。设置里可以直接跳到外观、大模型、语义索引、存储位置。

打星、旗标、加入选片、导出成品这些操作，在选中操作条和快捷键里都能完成，没有丢功能。

**研读与设置更清楚**

- 研读面板删掉了重复的说明文案，说明文字和正文拉开层级
- 设置左栏每项固定「标题 + 一行副标题」，不再被长文案撑得高低不一

**项目英文名统一为 photocoffer**

旧名 `lunaris` 容易和月球挂钩、望文生义。新版统一为 `photocoffer`（photo + coffer，照片宝库）。

- 旧版「月巢」「月相」的配置、器材库、日志会在首次启动时自动迁移，图库和偏好不用重配
- 已下载的语义模型直接复用，不用重下
- 确认新版正常后建议卸载旧版——两个版本同时开同一个图库会争 SQLite 锁

### 已知限制

- 安装包没有购买代码签名，Windows SmartScreen 与 macOS Gatekeeper 都会拦一次，按上面的说明放行即可
- RAW 只读内嵌预览图，不代替 Lightroom / Capture One 的显影
- 语义搜图与自动分类需要先建向量索引，首次耗时与图库规模相关

### 完整变更

- `feat`: 英文名统一为 photocoffer，版本升到 0.5.0
- `feat`: 顶部菜单精简为文件与设置
- `refactor`: 移除灯箱自动播放，收敛沉浸态判定
- `style`: 研读文案与设置左栏层级收敛
- `refactor(main)`: 平台判断统一走 `platform.ts` 常量
- `chore`: 对比度脚本改按边框分层判定
