## 存照 v0.6.0

给摄影师的本地图片库。照片留在你的硬盘上，找图、挑片、交付都在一个窗口里完成。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10 / 11 | `存照 Setup 0.6.0.exe` | 未签名，首次运行点「更多信息 → 仍要运行」 |
| macOS | 暂未提供预编译包 | 原生模块必须在 macOS 上安装，需从源码构建：`npm ci && npm run dist:mac` |

装完打开一次即可，不需要联网。

### 这次改了什么

**AI 可以完全用你自己的模型**

- 质量评分、后期建议、智能筛选、研读、自动分类，5 个能力都能在「设置 → 大模型 → 功能分配」里单独选模型。
- 本机 Ollama / 本机 OpenAI 兼容端点不需要 API Key；照片不出本机，也不计入额度。
- 外部模型继续按张数提醒：单次超过 10 张、今日超过 50 张软提醒，今日超过 100 张硬暂停；硬暂停只能等次日 0 点或手动重置。
- 设置页新增「本机 / 外部」标记和「能力与数据去向」表；每个 AI 入口都会显示照片会去哪里、今日已用多少。
- 自动分类：默认仍是本机零样本（免费、离线）；选中少量照片后可用自定义模型做精确标注，单次最多 12 张。
- 本机模型未启动时会直接提示检查 Ollama / 本地服务，不会误算成外部熔断。

**AI 用量闸门**

- 新增每日用量统计、软提醒、硬暂停与连续失败熔断。
- 批量评分、智能筛选、自动分类在调用前会先说明处理张数与预计消耗，确认后才发请求。

**稳定性**

- 修复快速翻片时旧照片的笔记覆盖新照片的问题。
- 修复提问保存失败时输入草稿丢失的问题。

### 升级说明

- 从 0.5.0 覆盖安装即可，图库、配置、器材库与已下载的语义模型都会保留。
- 旧版「月巢 / 月相」的配置仍会在首次启动时自动迁移。

### 已知限制

- 安装包没有购买代码签名，Windows SmartScreen 与 macOS Gatekeeper 都会拦一次，按上面的说明放行即可。
- RAW 只读内嵌预览图，不代替 Lightroom / Capture One 的显影。
- 语义搜图与自动分类需要先建向量索引，首次耗时与图库规模相关。
- 本机模型的识别质量取决于你本机运行的模型；存照负责路由与边界提示，不保证本机模型的效果。

### 完整变更

- `feat(llm)`: 区分本机与外部模型，本机调用免 Key、免计量
- `feat(ui)`: AI 入口增加数据去向与额度提示
- `feat(llm)`: 新增 AI 自动分类（自定义模型）
- `feat(llm)`: AI 用量配额闸门与设置页用量区块
- `fix(study)`: 修复翻片竞态与提问保存失败时的草稿恢复
- `docs`: 补充模型能力边界与可替换关系
- `chore`: 设计稿与产品方案移出公开仓库

---

**首次使用**：新建图库（或选已有照片目录）→ 导入照片 → 开始看。约 3 分钟，详见 [README](https://github.com/kaobei-renzhe/photocoffer#第一次打开约-3-分钟)。
