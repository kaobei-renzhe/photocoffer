## 存照 v0.7.0

给摄影师的本地图片库。照片留在你的硬盘上，找图、挑片、交付都在一个窗口里完成。

### 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10 / 11 | `photocoffer-0.7.0-win-x64-setup.exe` | 未签名，首次运行点「更多信息 → 仍要运行」 |
| macOS | 暂未提供预编译包 | 原生模块必须在 macOS 上安装，需从源码构建：`npm ci && npm run dist:mac` |

装完打开一次即可，不需要联网。

### 这次改了什么

**帮助菜单**

- 顶部菜单变成「文件 / 设置 / 帮助」。
- 「帮助 → 使用说明」打开离线弹层：三分钟上手、常用快捷键、常见问题都在里面，断网也能看。
- 弹层底部可以跳转到线上完整文档；只允许打开 https 链接。

**每个图库有自己的分类**

- 「设置 → 语义索引 → 分类类目」可以新增、改名、删除类目，默认 14 类，最多 30 个。
- 类目跟着图库走：两个图库可以用完全不同的分类体系。
- 改名会同步已有自动标注与标签；删除只删类目配置与自动关联，历史标注和手动打的同名标签保留。
- 本地零样本分类与大模型分类都只使用当前图库的类目。

**人像工作台不再要求下载模型**

- 移除了人像检测模型的下载入口与进度条。
- 不导入模型也能用人像工作台：跑过一次「自动分类」后，会按「人像」类目做粗筛。
- 判断顺序：人工标记 > 本地检测模型 > 自动分类「人像」类目。
- 想要更精确，可以在「设置 → 语义索引 → 人像检测模型」选择本地 `.onnx` 文件导入；只接受 43,102,531 字节的 int8 DETR 版本。
- 没导入模型时，空状态会引导去跑自动分类，不再提示下载。

**参考片开关移到研读 Tab**

- 信息 Tab 不再有「这是参考片」。
- 研读 Tab 顶部新增「参考片（学习用）」，勾选后仍会自动切到研读视角。
- 已标记的参考片状态不受影响。

**侧栏标签层级**

- 「全部 N 个标签」增加分隔线，与维度节点区分更明显。
- 维度节点左缩进、折叠箭头常显，hover 有整行背景反馈。

### 升级说明

- 从 0.6.0 覆盖安装即可，图库、配置、器材库、已有标注与已下载的语义模型都会保留。
- 老图库首次打开会自动升级结构（分类类目与查询索引），升级前会自动留一份备份。

### 已知限制

- 安装包没有购买代码签名，Windows SmartScreen 与 macOS Gatekeeper 都会拦一次，按上面的说明放行即可。
- RAW 只读内嵌预览图，不代替 Lightroom / Capture One 的显影。
- 语义搜图与自动分类需要先建向量索引，首次耗时与图库规模相关。
- 自动分类的「人像」只适合粗筛，不能当精确识别；需要精确检测请导入本地人像模型。
- 人像检测模型只支持本地导入，不提供应用内下载。

### 完整变更

- `feat(help)`: 新增帮助菜单与离线帮助弹层
- `feat(autotag)`: 分类类目按图库隔离，支持增删改名
- `feat(portrait)`: 移除人像模型下载，支持本地导入与三级降级
- `feat(inspector)`: 参考片开关移入研读 Tab
- `style(sidebar)`: 强化折叠标签与维度节点层级
- `fix(study)`: 翻片竞态与提问保存失败时的草稿恢复

---

**首次使用**：新建图库（或选已有照片目录）→ 导入照片 → 开始看。约 3 分钟，详见 [README](https://github.com/kaobei-renzhe/photocoffer#第一次打开约-3-分钟)。
