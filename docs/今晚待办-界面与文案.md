## 五、一条通用提醒

八份文档都写了「明确不做的事」，别让 Trae 自作主张：

| 别做 | 原因 |
| --- | --- |
| 删低频功能 | 方向是**收纳**不是砍，删了主人两周后自己会想不起来 |
| 换深色主题 | 深色不解决"复杂"，只是换个壳 |
| 加动画过渡 | 显得高级三分钟，然后开始觉得慢 |
| 给纯黑背景 | 暗调照片会看不出边界 |
| 做「简单/专业模式」开关 | 切了回不去、用户会怕点；改成功能随使用长出来 |
| 把 AI 评分、主色当摄影功能收掉 | 纯管理用户挑截图、按颜色找配图正需要它们 |
| 把 API Key 存进明文配置 | 现在是 DPAPI/Keychain 加密，安全性差一个量级 |
| 换本地嵌入模型 | 3.2 万条向量已建好，换 2B 级模型要全量重建，收益不抵代价 |
| 让全局温度覆盖能力温度 | 四个能力的温度差异是**功能设计**，不是用户偏好 |
| 把 API Key 导出到配置文件 | DPAPI 换机解不开，导出去是废文件；明文更不行 |
| 迁移时删掉旧目录的配置 | 万一新版有问题，用户还能回滚到旧版 |
| 把 CLIP 模型打进安装包 | 安装包从 145 MB 涨到 330 MB，按需下载即可 |
| 在平台间复用 `node_modules` | 唯一会让"分享出去的包启动即崩"的操作 |
| 把 `process.platform` 散落在组件里 | 一律走 `platform.ts`，否则以后改文案要翻遍全项目 |
