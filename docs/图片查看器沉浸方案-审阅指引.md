# 图片查看器沉浸方案 · 审阅指引

> 效果图：`design/cunzhao-lightbox.html`（自包含单文件，双击即开，内嵌主人自己的照片）
> **方案定调（2026-11-16 主人拍板）**：灯箱**固定黑色舞台，不随主界面主题变**，避免界面色干扰观看照片时的视觉引导。
> 产出：UI 设计全栈专家团（视觉方向 → 体验规范 → 前端落地），主理人汇编
> 日期：2026-11-16 · 项目 v0.4.1 · 浅色 classic/light 皮肤

## 0. 先说一个关键发现

**沉浸功能其实已经做进去了，只是藏在一个没人知道的快捷键里。**

`src/renderer/src/lib/chromeVisibility.ts`：

```ts
if (input.immersive) return input.peekBand
return !input.slideIdle
```

普通模式下 `chromeVisible` 恒为 `true` —— 三条胶囊**永远挂着**。只有按反引号 `` ` `` 开启「沉浸模式」，才会按鼠标位置（距顶/底各 68px 的 peek 带）显隐。

所以主人觉得「扎眼」不是缺功能，是**默认状态选错了**。这次改动的核心不是加东西，是把「沉浸」从隐藏快捷键变成开箱即用的默认状态。

## 1. 现在为什么显得复杂、扎眼

| # | 问题 | 具体位置 |
| --- | --- | --- |
| 1 | 三条 44px 白色实体胶囊常驻 | 顶部 620px、底左、底右 |
| 2 | 胶囊是「近白实体 + 1px 描边 + blur-18px」，在 #F4EEE4 舞台上是三块贴纸，边界比照片里的书架线条还硬 | 三处 `backdrop-blur-[18px] border border-[var(--lb-rule)]` |
| 3 | 顶栏 620px 横跨照片上方，15px 粗体文件名是全屏最重的文字，压住照片顶部 | `Lightbox.tsx:691` |
| 4 | 底右 11 个控件挤在一条里，图标 / 数字 / 中文混排，无分组无留白 | `Lightbox.tsx:925-1000` |
| 5 | 底左「没有器材信息」是空数据占位，仍占 240px 宽 | `Lightbox.tsx:905-922` |
| 6 | 舞台是浅米色 `#F4EEE4`（跟随 light 主题），暖调底会和照片的色温互相干扰 | `Lightbox.tsx:688` `bg-[var(--lightbox)]` |

**附带发现（真实 bug）**：左右翻页箭头用的是 `bg-white/8` + `text-white/80`，提示条是 `bg-black/70` —— 都是深色主题遗留，在浅米背景上箭头几乎看不见、提示条是一块突兀黑胶囊。

## 2. 效果图里看什么

效果图是 **左「现在」/ 右「提案」** 对照，右栏可亲手交互；下半部有专门的「交互演示台」，第一排四个按钮对应四态，第二排 chips 可单独复现滚轮 141% toast / 适应复位 / 旋转角度 toast / `⋯` 二级 / 首次提示，第三排是「锁定工具常显 / 高对比 / 减少动效」三个开关，左侧有带倒计时进度条的实时状态行。请重点看这 4 个状态：

| 态 | 怎么触发 | 该看到什么 |
| --- | --- | --- |
| ① **静止沉浸** | 打开后不动鼠标，或轻微抖一下 | 看不到任何按钮、胶囊、边框、箭头；只有一张被浅暖灰衬起来的照片，和上下两行几乎融进背景的浅灰小字 |
| ② **边缘唤出** | 鼠标移到窗口顶部或底部 68px 内 | 工具条 150ms 淡入；`⋯` hover 展开二级；停在工具条上不会消失；移开 3s 后淡出 |
| ③ **键盘与高对比** | 按 Tab，或点「锁定工具常显」 | Tab 一聚焦整条即淡入且冻结计时，每个控件有焦点环；`?` 面板能看全部快捷键 |
| ④ **让路** | 点演示按钮（幻灯片 / 框选 / 档案） | 操作期间工具条保持可见，有明确退出，不会中途消失 |

**验收一句话**：静止第一眼看不到任何按钮、胶囊或边框，只有照片和两行几乎融进背景的浅灰小字；鼠标一动工具才浮出来，移开又悄悄退回去。

## 3. 方案要点（B · 重组）

### 视觉（黑底口径）
- **灯箱固定黑色舞台**：`#0B0B0B`（效果图可切 纯黑 `#000` / 深炭 `#141414`），不随主界面主题
- **实现要点**：现在灯箱用 `bg-[var(--lightbox)]`，而 `--lightbox` 在 light 主题下被覆盖成 `#F4EEE4`（`styles.css:118/237`）。要固定黑**不能改 `--lightbox`**（会连带影响主界面），应给灯箱单独一组固定深色变量，或给灯箱根节点加独立主题作用域
- 黑底上**不要白衬、不要暖棕投影**：白衬会变成刺眼白框，暖棕投影在纯黑上根本看不见
- 只留 `1px rgba(255,255,255,.10)` **勾边** —— 这不是装饰，是防夜景 / 低调人像的暗部边缘和纯黑背景融成一片
- 文字 `#F2F2F2` / 浅字 `#A6A6A6`；强调色换 `#FDC75D`（原暖棕 `#A66C00` 在黑底上对比太低）
- 照片占舞台高度约 79–86%，四周留白 ≥48px；工具条放在照片下方的黑区里，**不压照片**
- **去掉三条实体胶囊**，改无底 / 无框 / 无 blur 的浮字
- 顶栏胶囊 → 只剩 13.5px 文件名 + 计数；`×` / `?` / `档案` 降为 hover 图标
- 控件透明度三档：静止 `.38` / 触发 `.72` / hover `1`
- 动效只做 opacity：淡入 150ms、淡出 200ms

### 体验（两条重要否决）
1. **否定「任意 pointermove 就淡入」** —— 主人会长时间单张凝视，手一抖工具条反复弹隐比常显更烦。改为：进入上下 68px 带才淡入；辅助触发需累计位移 ≥32px 且驻留 ≥150ms，设 <8px 抖动死区；淡出延迟 3s。
2. **禁止 `inert` / `aria-hidden` / `display:none`** —— 那等于对键盘和读屏用户直接删功能。控件常驻 DOM 与 a11y 树，静止只降 opacity + `pointer-events:none`，靠 `:focus-within` 让 Tab 一聚焦即淡入并冻结计时。

### 控件收敛：11 → 5 常显
| 常显 | 收进 `⋯` 二级 | 改成别的形态 |
| --- | --- | --- |
| 缩放−、缩放+、适应、`⋯`、`×` | 播放/暂停、3 秒、左右转、全屏、`?` | 翻页 → 左右大热区 + 唤出态箭头；`141%` / `0°` → 数值变化时 1s toast |

二级 **hover 即展开、不用点击**，展开期间冻结淡出。播放态必须锁定常显一个「停止」出口。

### 连带反转：之前说的「深色遗留 bug」现在不用改了

上一版方案基于浅色舞台，判定箭头 `bg-white/8 + text-white/80`、提示条 `bg-black/70` 是"深色主题遗留 bug"。
**灯箱改回黑色之后，这些值本来就是对的** —— 白色半透明按钮 + 浅色图标正是深色灯箱的正确写法。

| 位置 | 结论 |
| --- | --- |
| 箭头 `:840/:854` `bg-white/8` + `text-white/80` | ✅ **不用改**，深色下正确 |
| 提示条 `:868` `bg-black/70` | ✅ **不用改** |
| 档案侧栏 `:876` `border-white/10` | ✅ **不用改** |
| 帮助面板 `:732` `shadow-xl` | 可留，建议统一成 `--shadow-3`（深色版更重） |

> 仍建议把这些写死值收敛成 `--lb-*` 变量（便于以后调），但**值本身不要再动**。

> **⚠️ 误伤警告**：框选草稿 `border-[#F2F5F8]` 近白虚线 + 黑外描边 `:1094`，是压在照片上、保证任意明暗照片都可见的**刻意双描边**，不是 bug。别一刀切换成 `--lb-*` 变量，否则深色照片上会消失。

> 胶囊内部的文字 / 图标 / 分隔线**已经全部走 `--lb-*` 变量**，没有写死白色。所以「扎眼」纯粹是容器形态问题，去掉容器即可，色值不用动。

### 黑底带来的两个副作用（需要主人确认）

**① 从浅色主界面点开照片会突然全黑。**
这是 Lightroom / Capture One / 系统「照片」的通行做法（看片时主动排除界面干扰），但明暗跳变比较强。如果觉得刺眼，可以在打开时加 120–150ms 的明度过渡（淡入到黑），代价是多一层动画——默认建议**不加**，专业软件都是瞬切。

**② 暗调照片的边界会消失。**
夜景、低调人像、黑底棚拍，照片边缘和纯黑背景会糊成一片，看不出照片到哪结束。所以那 `1px rgba(255,255,255,.10)` 勾边**不是装饰，是功能性必需**——如果实际用下来觉得多余，可以降到 `.06`，但不建议完全去掉。

## 4. 明确不做

| 别做 | 原因 |
| --- | --- |
| 换深色主题 | 深色不解决「复杂」，只是换个壳；且当前皮肤是浅暖米 |
| 加动画过渡（缩放/位移/回弹） | 显得高级三分钟，然后开始觉得慢；只做 opacity |
| 静止态显示箭头或常驻提示条 | 会重新变成「元素扎眼」 |
| 删掉 `6 / 200` 计数 | 它是方位锚点，静止态唯一的低对比信息 |
| 给右上角 Windows 三键做设计 | 系统层，不可改，不纳入收纳 |
| 顺手改舞台以外的 app 界面 | 本次只动灯箱 |
| 把框选虚线换成主题变量 | 见上方误伤警告 |
