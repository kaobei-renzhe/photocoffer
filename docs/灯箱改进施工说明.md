## 2. 详细改法

### 2.1 背景加深

**第 503 行：**

```diff
- <div className="fixed inset-0 z-50 flex flex-col bg-[rgba(5,7,10,0.94)]">
+ <div className="fixed inset-0 z-50 flex flex-col bg-[rgba(4,5,10,0.97)]">
```

**为什么不直接给纯黑**：暗调照片（夜景、低调人像、黑底棚拍）的黑色边缘会和纯黑背景融成一片，用户看不出图片到哪里结束。留 3% 的差异，既能保住沉浸感，又有边界。

这个数字可以按主人的审美微调，0.96–0.98 之间都行。

### 2.2 控件自动隐藏（主要工作量）

#### 第一步：新增 `src/renderer/src/hooks/useIdle.ts`

```ts
import { useEffect, useState } from 'react'

/**
 * 指针和键盘静止 delay 毫秒后返回 true；任何输入立即回到 false。
 * 用于灯箱、视频播放器这类「看的时候不该有控件」的场景。
 */
export function useIdle(delay = 2000): boolean {
  const [idle, setIdle] = useState(false)

  useEffect(() => {
    let timer: number | null = null

    const wake = (): void => {
      setIdle(false)
      if (timer !== null) window.clearTimeout(timer)
      timer = window.setTimeout(() => setIdle(true), delay)
    }

    wake()
    window.addEventListener('pointermove', wake, { passive: true })
    window.addEventListener('pointerdown', wake, { passive: true })
    window.addEventListener('keydown', wake)
    return () => {
      if (timer !== null) window.clearTimeout(timer)
      window.removeEventListener('pointermove', wake)
      window.removeEventListener('pointerdown', wake)
      window.removeEventListener('keydown', wake)
    }
  }, [delay])

  return idle
}
```

#### 第二步：在 `Lightbox` 里接上

```tsx
import { useIdle } from '../hooks/useIdle'

// 组件内，和别的 useState 放一起
const idle = useIdle(2000)
const chrome = `transition-opacity duration-300 ${idle ? 'opacity-0 pointer-events-none' : 'opacity-100'}`
```

#### 第三步：三处应用

**顶栏（504 行）**

```diff
- <div className="h-[46px] shrink-0 px-4 flex items-center gap-3 text-[12.5px]">
+ <div className={`h-[46px] shrink-0 px-4 flex items-center gap-3 text-[12.5px] ${chrome}`}>
```

**底栏（654 行，认 `h-[34px]` 那个）**

```diff
- <div className="h-[34px] shrink-0 px-4 flex items-center gap-3 text-[11px] ...">
+ <div className={`h-[34px] shrink-0 px-4 flex items-center gap-3 text-[11px] ... ${chrome}`}>
```

**左右箭头**：不要完全消失，留一点痕迹

```diff
- className="absolute left-3 top-1/2 ... bg-white/8 hover:bg-white/16 ..."
+ className={`absolute left-3 top-1/2 ... bg-white/8 hover:bg-white/16 transition-opacity duration-300 ${idle ? 'opacity-15' : 'opacity-100'}`}
```

理由：**用户需要知道"还有下一张"**。完全消失会让人以为到头了。

#### 三个必须处理的细节

**① 淡出后要 `pointer-events-none`**

顶栏和底栏淡出后如果还能点，用户会误触到看不见的按钮（正好点到"关闭"就尴尬了）。

左右箭头例外——它们是导航核心，保留 `pointer-events`，只是变淡。

**② 操作后要短暂唤醒**

翻页、旋转、缩放之后，底栏应该露一下让人看到反馈（比如旋转了 90°）。

不用额外写代码：这些操作都通过点击或键盘触发，本身就会 `wake()`。**但如果是程序自动触发的（比如方向键翻页后延迟复位）要手动调一次。**

**③ 框选模式下不要淡出**

用户正在拖框，顶底栏突然消失会让人以为出错了。

```tsx
const idleRaw = useIdle(2000)
const idle = idleRaw && !drawing
```

⚠️ **不要写成 `useIdle(2000) && !drawing`** —— 那样 hook 在短路表达式里被条件调用，React 会直接报错。必须先拿到 hook 返回值，再做逻辑与。

### 2.3 快捷键提示收进 `?`

**第 663 行**，把那一长串删掉：

```diff
- <span className="ml-auto truncate">
-   滚轮缩放 · 双击 100% · R 旋转 · ← → 切换 · N 档案 · F 框选 · Esc 关闭
- </span>
```

**顶栏加一个 `?` 按钮**（放在关闭按钮左边）：

```tsx
const [helpOpen, setHelpOpen] = useState(false)

<button
  className="btn btn-ghost h-7 px-2"
  onClick={() => setHelpOpen((open) => !open)}
  title="快捷键"
>
  <CircleHelp size={15} />
</button>
```

**气泡内容**（绝对定位，点外部关闭）：

```tsx
{helpOpen && (
  <div
    className="absolute right-3 top-12 z-10 w-[240px] rounded-lg border border-white/12 bg-[#14171e] p-3 text-[11.5px] shadow-xl"
    onMouseLeave={() => setHelpOpen(false)}
  >
    {[
      ['滚轮', '缩放'],
      ['双击', '100%'],
      ['0', '适应窗口'],
      ['R / Shift+R', '旋转'],
      ['← →', '上一张 / 下一张'],
      ['N', '档案面板'],
      ['F', '框选'],
      ['Esc', '关闭']
    ].map(([k, v]) => (
      <div key={k} className="flex justify-between py-[3px]">
        <span className="text-[var(--faint)]">{k}</span>
        <span className="text-[var(--text)]">{v}</span>
      </div>
    ))}
  </div>
)}
```

`CircleHelp` 从 `lucide-react` 引（项目已经在用这个库）。

**额外收益**：底部那行空出来后，EXIF 信息（机身 / 镜头 / 光圈 / 快门 / ISO）能有更多横向空间，现在被那串提示挤得 `max-w-[280px]` 截断。

## 5. 可选：图片留白

现在图片上下几乎顶到边栏。加 8–12px padding 会更透气。

⚠️ **但这个改动有风险**：`stageRef` 的尺寸参与"适应窗口"的计算（`shownW / shownH` 那一套）。加 padding 之后 fit 尺寸要同步减掉，否则图片会溢出或被裁。

如果要做，改完必须验证：
- 适应窗口（`0` 键）后图片完整显示
- 放大到 100% 后拖动，边界正常
- 旋转 90° 后仍然居中

**建议单独做、单独验**，别和上面三条混在一起。

## 明确不做的

| 别做 | 原因 |
| --- | --- |
| 让档案面板默认展开 | 灯箱是全屏看图，默认展开会挤掉一半画面。必须默认收起 |
| 左右箭头完全隐藏 | 用户会以为到头了。留 15% 痕迹 |
| 给纯黑背景 | 暗调照片的边缘会和背景融成一片，看不出图片到哪结束 |
| 把淡出做成"打开后 N 秒隐藏" | 那是动画，不是沉浸。要的是**指针静止才淡出**，一动就回来 |
| 淡出后仍保留可点击 | 用户会误点到看不见的按钮，正好点到「关闭」就尴尬了 |
| 框选模式下也淡出 | 正在拖框时控件消失，用户会以为出错了 |
| 顺手调缩放的显示文案 | `percent` 本来就是百分比，是对的。我先前说它要改，是我看错了 |
